Deckxpert Simulation UI

If you reached this page from http://localhost:8080/sim_harness/, Apache is serving static files, but the interactive simulation dashboard runs as a Python web app.

Start dashboard:

python -m sim_harness.web --host 127.0.0.1 --port 8765

Then open: http://127.0.0.1:8765.

This avoids Apache 403/Forbidden on directory routes and gives full deck upload, simulation run, and turn-by-turn legality inspection.
